# adobe-bridge-script

Adobe Bridge 用の ExtendScript / JSX スクリプト置き場です。

## sync-jpg-rating-to-raw.jsx

`sync-jpg-rating-to-raw.jsx` は、JPG フォルダ内の `.jpg` / `.jpeg` と、別フォルダにある同名 RAW ファイルの間でレーティングを同期します。

JPG / RAW ファイルをコピーしたり、ファイル名を変更したり、ファイルを削除したりはしません。変更するのは、同期先の同名ファイルが 1 件だけ見つかり、同期元と同期先のレーティングが異なる場合の同期先レーティングだけです。

### 使い方

1. `sync-jpg-rating-to-raw.jsx` を Adobe Bridge の起動スクリプトフォルダに配置します。
2. Adobe Bridge を再起動します。
3. `Tools` メニューから同期方向に合うコマンドを実行します。
   - `JPGのレーティングを同名RAWに同期`
   - `RAWのレーティングを同名JPGに同期`
4. レーティング元のフォルダを選択します。
5. レーティング反映先のフォルダを選択します。
6. 完了ダイアログで同期結果を確認します。

フォルダ選択ダイアログは、可能な場合は Bridge で現在表示・選択されているフォルダを初期フォルダとして開きます。

### 配置場所の例

環境や Bridge のバージョンによりパスは異なります。

- macOS: `~/Library/Application Support/Adobe/Bridge <version>/Startup Scripts/`
- Windows: `%APPDATA%\Adobe\Bridge <version>\Startup Scripts\`

Bridge の `Preferences > Startup Scripts` から、起動スクリプトの場所や有効状態を確認してください。

### 対象拡張子

JPG 側:

- `.jpg`
- `.jpeg`

RAW 側:

- `.raf`
- `.dng`
- `.cr2`
- `.cr3`
- `.nef`
- `.arw`
- `.orf`
- `.rw2`
- `.pef`
- `.sr2`
- `.srf`

RAW 拡張子を増減したい場合は、スクリプト上部の `RAW_EXTENSIONS` を編集してください。

### 注意点

- 対象は選択したフォルダ直下のファイルのみです。サブフォルダは再帰処理しません。
- Bridge の現在フォルダを取得できない場合、同期先フォルダ選択では同期元フォルダの親フォルダを初期フォルダとして使います。
- 拡張子判定は大文字小文字を区別しません。
- ベースファイル名も、OS 差異を避けるため大文字小文字を区別せず照合します。
- 同じベースファイル名で同期先候補が複数ある場合は、安全のため同期せずスキップします。
- 同期元のレーティングが `0` の場合も、同期先と異なれば反映します。
- 同期元と同期先のレーティングが同じ場合は、不要なメタデータ書き込みを避けるため更新しません。
- 処理は複数ワーカーのバッチに分割して実行します。ExtendScript / Bridge の制約上 OS スレッドを直接増やすものではありませんが、複数のファイル処理を並行的に進めます。
- RAW のレーティングは Bridge / Camera Raw の設定により XMP サイドカーへ反映される場合があります。必要に応じて Bridge のメタデータ設定を確認してください。

### 動作確認観点

- Bridge 起動後、`Tools` メニューに JPG→RAW と RAW→JPG の 2 つの同期コマンドが表示されること。
- 同期元フォルダ選択をキャンセルした場合、処理が中止されること。
- 同期先フォルダ選択をキャンセルした場合、処理が中止されること。
- `DSCF0001.jpg` と `DSCF0001.raf` のような同名ペアで、JPG の `0` / `1`〜`5` が RAW 側へ反映されること。
- `DSCF0001.raf` と `DSCF0001.jpg` のような同名ペアで、RAW の `0` / `1`〜`5` が JPG 側へ反映されること。
- 同期元と同期先のレーティングが同じ場合、更新件数ではなく「同一レーティングのため更新しなかった件数」に入ること。
- `DSCF0001.raf` と `DSCF0001.dng` のように同期先候補が複数ある場合、同期されずスキップ件数に入ること。
- 同名の同期先ファイルがない同期元ファイルが、未検出件数に入ること。
- `.JPG` / `.JPEG` / `.RAF` など、大文字小文字違いの拡張子でも対象になること。
